# Model Card: Hermes Whisper

## Статус

**Research implementation; продуктивні ваги відсутні.**

Версія 0.1 містить повний код навчання з випадкової ініціалізації. Smoke
checkpoint, який генерується тестом на синтетичних тонах, не є мовною моделлю і
не повинен поширюватися як навчений STT.

## Заплановане призначення

- українська та чеська диктовка;
- локальне транскрибування файлів;
- технічна, будівельна, юридична й офісна лексика після включення дозволених
  навчальних даних;
- робота без обов'язкової хмарної передачі аудіо.

## Не призначено

- приховане записування людей;
- біометрична ідентифікація speaker;
- прийняття юридичних, медичних або безпекових рішень без перевірки людиною;
- транскрибування мов, яких немає в model card;
- використання confidence як гарантованої ймовірності правильності;
- обробка секретної/службової інформації без окремого захищеного середовища.

## Метрики

WER, CER, language accuracy, RTF і domain slices ще не заповнені, тому що
продуктивні ваги й закритий test-набір не створені.

Жодне твердження про точність не допускається до відтворюваного benchmark.

## Відомі ризики

- hallucination на тиші, музиці або невідомій мові;
- помилки в іменах, цифрах, датах і одиницях;
- нерівна якість між українською та чеською;
- деградація на акцентах, шумі та невідомих мікрофонах;
- упередження через дисбаланс speakers і доменів;
- можливе відтворення чутливих фрагментів за неправильного формування
  датасету.

## Release gate для ваг

Публікація або інтеграція дозволяється тільки після:

1. data license/consent audit;
2. speaker/source leakage check;
3. закритого test benchmark;
4. error analysis по мовах і доменах;
5. тесту на тиші, шумах та out-of-language audio;
6. security/privacy review;
7. заповнення фактичних метрик у цій картці.
