# Security and privacy

- Навчання та inference не містять мережевих викликів.
- Manifest validator вимагає `consent=true`.
- Чекпойнти та `.hws` перевіряються SHA-256.
- Завантажуйте тільки власні або довірені checkpoints.
- PyTorch `model.pt` не є sandbox-контейнером; не відкривайте невідомі моделі.
- Не включайте приватні manifests, audio або checkpoints у публічний git.
- Logs за замовчуванням містять метрики, а не повні транскрипції.

Поточна версія не має шифрування даних at rest. Це відповідальність файлової
системи/середовища навчання до появи окремого encrypted storage layer.
