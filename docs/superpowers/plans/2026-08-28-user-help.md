# VOICE Studio User Help Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add verified Ukrainian user documentation, searchable in-app Help, packaged Help assets, and an incremental `/sync-help` project skill.

**Architecture:** `docs/help/` is the only authored manual. `voice_studio.help_content` validates, searches, and parses those Markdown topics. The Tk application renders the parsed blocks, while wheel and PyInstaller configuration distribute the same canonical files.

**Tech Stack:** Python 3.11/3.12, Tkinter/ttk, Markdown text, JSON manifest, setuptools, PyInstaller, pytest, Ruff.

**Spec:** `docs/superpowers/specs/2026-08-28-user-help-design.md`

## Global Constraints

- Default documentation language is Ukrainian.
- Do not invent behavior, validation, formats, shortcuts, or verified scope.
- Keep `docs/help/` canonical; do not hardcode a second manual in Python.
- Preserve local/private defaults and all current product workflows.
- Use no new runtime dependency or documentation framework.
- Ship the same Help files in source, wheel, and Windows bundle.
