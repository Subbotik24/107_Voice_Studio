# Управління навчальними даними

## Обов'язковий мінімум

Кожний record повинен мати:

- ідентифіковане джерело;
- задокументований режим використання або ліцензію;
- `consent=true`;
- технічну можливість виключити record із наступної версії датасету;
- незмінний `record_id` або інший відтворюваний ключ.

Validator навмисно відхиляє `consent=false`.

## Заборонено автоматично включати

- судові справи та документи з персональними даними;
- матеріали з військовою або службовою інформацією;
- записи третіх осіб без їхньої згоди;
- приватні телефонні розмови;
- комерційні матеріали без права на model training;
- аудіо з невідомою ліцензією;
- синтетичне аудіо, видане за реальне без окремого маркування.

Такі дані можуть використовуватися лише після окремої правової, безпекової та
приватнісної перевірки. Наявність файла на комп'ютері не є згодою на навчання.

## Мінімізація

- зберігати тільки необхідний audio segment;
- не переносити зайві metadata;
- speaker ID робити псевдонімом;
- вести окремий список відкликаних records;
- не публікувати приватний manifest разом із кодом;
- train logs не повинні містити повний текст приватних записів.

## Версійність

Для кожного запуску фіксуються:

- manifest fingerprint;
- tokenizer JSON;
- config fingerprint;
- checkpoint SHA-256;
- джерела й ліцензійні умови;
- правила нормалізації;
- дата створення dataset snapshot.

Якщо змінюється будь-який із цих компонентів, це новий dataset/model run.
