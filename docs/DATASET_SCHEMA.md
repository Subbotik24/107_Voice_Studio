# Контракт навчального датасету

## Формат

Один UTF-8 JSON object на рядок (`.jsonl`):

```json
{
  "audio": "audio/uk-000001.wav",
  "text": "Технічний опис проєкту.",
  "language": "uk",
  "duration_seconds": 2.41,
  "provenance": {
    "source": "user-owned-recording",
    "license": "private-training-only",
    "consent": true,
    "speaker_id": "speaker-001"
  },
  "record_id": "uk-000001",
  "split": "train",
  "segments": [],
  "metadata": {
    "microphone": "example"
  }
}
```

## Поля

| Поле | Обов'язкове | Умова |
|---|---|---|
| `audio` | так | абсолютний або відносний до manifest шлях |
| `text` | так | непорожня еталонна транскрипція |
| `language` | так | `uk` або `cs` |
| `duration_seconds` | так | додатне число, не більше model chunk |
| `provenance.source` | так | точне джерело запису |
| `provenance.license` | так | ліцензія/режим використання |
| `provenance.consent` | так | має бути `true` |
| `provenance.speaker_id` | рекомендовано | стабільний псевдонім speaker |
| `record_id` | рекомендовано | унікальний стабільний ID |
| `split` | ні | `train`, `validation`, `test`; default `train` |
| `segments` | ні | phrase-level timestamps |
| `metadata` | ні | мікрофон, домен, шум, регіон тощо |

Під час завантаження фактична тривалість аудіо порівнюється з manifest.
Допустиме технічне відхилення — 0,1 с; більше відхилення вважається помилкою
метаданих або неправильним файлом.

## Сегменти

```json
{
  "segments": [
    {"start": 0.0, "end": 1.2, "text": "Перший фрагмент."},
    {"start": 1.2, "end": 2.4, "text": "Другий фрагмент."}
  ]
}
```

Правила:

- `0 <= start <= end <= duration_seconds`;
- сегменти впорядковані;
- перетини заборонені;
- текст кожного сегмента непорожній;
- час є відносним до поточного аудіофайла.
- нормалізоване з'єднання всіх `segments[].text` має дорівнювати полю `text`.

## Текст

Нормалізація обмежена:

- Unicode NFC;
- NBSP перетворюється на звичайний пробіл;
- zero-width space видаляється;
- послідовності whitespace стискаються;
- регістр, пунктуація, апострофи та діакритика зберігаються.

Транскриптор має зафіксувати окрему політику для:

- чисел;
- скорочень;
- одиниць вимірювання;
- нерозбірливих місць;
- стороннього мовлення;
- шумів;
- code-switching.

Не можна довільно змішувати різні політики між записами.

## Split

Розподіл робиться до тренування за групою, а не випадковим рядком:

- один speaker — лише в одному split;
- один довгий вихідний запис — лише в одному split;
- дублікати та майже дублікати — лише в одному split;
- серії одного документа/диктування — лише в одному split.

Інакше test WER буде штучно заниженим.
