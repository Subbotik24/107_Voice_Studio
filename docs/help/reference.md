# Довідка екранів і параметрів

## Ліве меню

| Елемент | Призначення |
|---|---|
| **Студія** | Головний робочий екран транскрибування й редактор. |
| **Історія** | Переводить фокус до локального списку транскриптів. |
| **Моделі** | Імпорт, download, verification і видалення моделей `faster-whisper`. |
| **Резервна копія** | Створення, перевірка та відновлення `.voice-backup`. |
| **Налаштування** | Мова інтерфейсу, розпізнавання, local AI та privacy defaults. |
| **Довідка** | Відкриває цей manual; також доступна через F1. |

На широкому вікні праворуч показується панель **Готовність**. За меншої ширини
вона приховується, а ліве меню переходить у компактний режим.

## Головний екран

| Елемент | Призначення | Примітка |
|---|---|---|
| **Транскрибувати файл…** | Вибрати медіафайл і запустити поточний STT-движок. | Cloud-движок потребує окремої згоди. |
| **● Утримуйте для запису** | Записувати, доки кнопка утримується. | Після відпускання починається обробка. |
| **● Постійний запис** | Почати запис без утримування. | Повторна дія зупиняє запис. |
| **Скасувати** | Скасувати поточну довгу операцію. | Кнопка активна лише під час роботи. |
| **Копіювати текст** | Явно помістити виправлений текст у clipboard. | Потрібен відкритий транскрипт. |
| **Виправлений текст** | Редагований текст. | Зберігається окремо від raw output. |
| **Оригінал** | Незмінний STT output. | Лише читання. |
| **Дані** | Структуровані metadata. | Може містити технічні значення движка. |

## Налаштування → Загальні

| Поле | Значення | Поведінка |
|---|---|---|
| **Мова інтерфейсу** | `Українська`, `Čeština`, `English` | Застосовується одразу після **Зберегти**. |
| **Зберігання аудіо** | `keep`, `delete_after_transcription` | Другий режим стосується лише керованої копії; оригінал не видаляється. |
| **Гаряча клавіша** | Непорожня Tk/pynput-комбінація; default `<f13>` | **Запам’ятати клавішу…** очікує натискання; Esc скасовує. |
| **Автоматично копіювати результат у буфер обміну** | Увімкнено/вимкнено | Вимкнено за замовчуванням. |
| **Offline-only: заборонити мережеві операції** | Увімкнено/вимкнено | Блокує cloud STT, OpenAI cleanup і download моделі. |

## Налаштування → Розпізнавання

| Поле | Допустимі значення/обмеження | Призначення |
|---|---|---|
| **Движок** | `faster-whisper`, `openai-cloud` | Local є стандартним; cloud не є fallback. |
| **Мова транскрипції** | `auto`, `uk`, `cs`, `en` | Не залежить від мови інтерфейсу. |
| **Модель** | Непорожній ID встановленої моделі або локальна директорія | Для `faster-whisper`. Default `small`. |
| **Пристрій** | Непорожній runtime value | Default `auto`. |
| **Тип обчислень** | Непорожній runtime value | Default `default`. |
| **Модель OpenAI STT** | Непорожній model ID | Default `gpt-transcribe`; використовується лише cloud STT. |
| **Словник JSON** | Шлях до валідного JSON або порожнє поле | Детерміновані термінологічні заміни після STT. |

Задача має внутрішній timeout від 60 до 86 400 секунд; поточний UI не показує
окреме поле для нього. Default — 7 200 секунд.

## Налаштування → Локальний AI

| Поле/дія | Значення | Призначення |
|---|---|---|
| **Провайдер AI-редагування** | `ollama`, `openai` | Default `ollama`. |
| **Локальна модель Ollama** | Одна зі знайдених локальних моделей | **Оновити** повторює discovery. |
| **Модель OpenAI для AI-редагування** | Непорожній model ID | Default `gpt-4.1-mini-2025-04-14`. |
| **Задати / замінити ключ OpenAI** | API key | Зберігається в OS keychain, не в settings. |
| **Видалити ключ** | — | Видаляє keychain entry. |
| **Статус** | — | Показує джерело ключа без самого значення. |
| **Перевірити з’єднання** | — | Виконує явну мережеву перевірку OpenAI. |

OpenAI cleanup надсилає лише виправлений текст і segment indexes після окремої
згоди. Raw text не надсилається. Ollama працює через loopback і не потребує API
key або cloud consent.

## Підтримувані медіа

Локальний file picker приймає такі розширення:

| Аудіо | Відеоконтейнери |
|---|---|
| WAV, MP3, M4A, FLAC, OGG, OPUS, AAC | MP4, MOV, MKV, WEBM |

Файл перевіряється в окремому disposable process. Основні межі: 2 GiB, дві
години, щонайменше одна декодована аудіодоріжка. FFmpeg/PyAV runtime має
підтримувати фактичний codec усередині контейнера.

OpenAI cloud STT приймає MP3, MP4, MPEG, MPGA, M4A, WAV та WEBM і відхиляє файл
понад 25 MB без прихованого поділу або стискання.

## Формати експорту

| Формат | Вміст |
|---|---|
| TXT | Виправлений текст і завершальний newline. |
| MD | Назва, мова, движок, модель, тривалість, RTF, SHA-256 і виправлений текст. |
| JSON | Повний структурований transcript payload. |
| SRT | Сегменти з SRT timestamps. |
| VTT | Сегменти з WebVTT timestamps. |

## Клавіатура

| Клавіша | Дія |
|---|---|
| F1 | Відкрити **Довідка**. |
| Enter у пошуку історії | Виконати **Пошук**. |
| Enter або Ctrl+Enter у редакторі | Вставити новий рядок. |
| Esc під час захоплення hotkey | Скасувати захоплення. |
| Esc у вікні довідки | Закрити довідку. |

## Дані й приватність

- Локальний STT є default. Cloud запускається лише явною дією.
- Початковий медіафайл користувача ніколи не видаляється.
- `raw_text` незмінний; зберігаються лише правки `corrected_text` і formatting.
- API keys не потрапляють у settings, transcript metadata, backup або
  diagnostics.
- Автоматичне копіювання в clipboard вимкнене за замовчуванням.
- **diagnostics** створює redacted report; не публікуйте приватне аудіо,
  транскрипти, бази даних, ключі або повні локальні шляхи.

## CLI для досвідчених користувачів

Desktop UI є основним способом роботи. Повний актуальний список CLI-команд:

```text
voice-studio --help
voice-studio COMMAND --help
```

Основні команди: `transcribe`, `history`, `show`, `export`, `cleanup`,
`cleanup-undo`, `models`, `backup`, `diagnostics`, `doctor`, `health`.
Cloud transcription потребує `--allow-cloud-upload`, а OpenAI cleanup —
`--allow-cloud-text`; застосування cleanup додатково потребує `--apply`.
