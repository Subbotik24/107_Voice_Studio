# Швидкий старт

Мета: отримати перший приватний транскрипт через установлену локальну Ollama.

## 1. Запуск

Відкрийте **VOICE Studio.exe**. Програма одразу показує головне вікно й не
відкриває майстер початкового налаштування. Для portable-збірки спочатку
розпакуйте весь ZIP разом із папкою **VOICE Studio**.

## 2. Перевірка локальної моделі

1. Запустіть Ollama у Windows.
2. Відкрийте **Налаштування → Профілі**.
3. Залиште вибраним **Локальна Ollama**.
4. На вкладці **Локальний AI** перевірте **Локальна модель Ollama**.
5. Натисніть **Оновити**, якщо список порожній, потім **Зберегти**.

Під час першого запуску VOICE Studio у фоні знаходить тільки моделі, які Ollama
позначає як аудіосумісні. Якщо вибору ще немає, програма зберігає відповідну
встановлену модель. Збережений вибір не замінюється мовчки.

## 3. Вхідні дані

Підготуйте файл із голосом: WAV, MP3, M4A, FLAC, OGG, OPUS, AAC, MP4, MOV, MKV
або WEBM. Файл повинен містити аудіодоріжку, бути не порожнім, не перевищувати
2 GiB і дві години. Профіль **Локальна Ollama** приймає до 30 хвилин за одну
транскрипцію; для довшого запису виберіть **Локальний Whisper**.

## 4. Виконання

1. На екрані **Студія** натисніть **Транскрибувати файл…**.
2. Виберіть медіафайл.
3. Дочекайтеся фаз імпорту, розпізнавання, збереження та локального
   AI-виправлення.
4. Для припинення натисніть **Скасувати**.

Ollama отримує підготовлений WAV лише через `127.0.0.1:11434`. Whisper і OpenAI
не запускаються як прихований fallback.

## 5. Результат

- **Виправлений текст** — робоча версія після словника й локального
  AI-виправлення;
- **Оригінал** — незмінний текст першого розпізнавання;
- **Дані** — движок, модель, тривалість та інші metadata;
- **Історія** — локально збережений запис.

Якщо другий Ollama-запит для виправлення не вдався, транскрипт усе одно
зберігається й відкривається з попередженням.
