# Довідка екранів і параметрів

## Ліве меню

| Елемент | Призначення |
|---|---|
| **Студія** | Запис, транскрибування, редактор та історія. |
| **Моделі** | Керування тільки моделями Faster Whisper. |
| **Резервна копія** | Створення, перевірка й відновлення backup. |
| **Налаштування** | Профілі, мова, движки, Ollama й OpenAI. |
| **Довідка** | Відкриває manual; також F1. |

## Налаштування → Профілі

| Профіль | Розпізнавання | AI-виправлення | Мережа |
|---|---|---|---|
| **Локальна Ollama** | Ollama audio model | Ollama, автоматично | Лише loopback |
| **Локальний Whisper** | Faster Whisper | Вимкнено | Локально |
| **OpenAI cloud** | `gpt-transcribe` або збережений ID | OpenAI вручну | Явна згода |

## Налаштування → Загальні

| Поле | Значення / поведінка |
|---|---|
| **Мова інтерфейсу** | `Українська`, `Čeština`, `English`; змінює також Help. |
| **Зберігання аудіо** | `keep` або `delete_after_transcription`; оригінал не видаляється. |
| **Гаряча клавіша** | Default `<f13>`; **Запам’ятати клавішу…** записує нову. |
| **Автоматично копіювати** | Вимкнено за замовчуванням. |
| **Offline-only** | Визначається профілем; локальні профілі не дозволяють cloud. |

## Розпізнавання і Local AI

| Поле | Призначення |
|---|---|
| **Движок** | Поточний движок, який визначено профілем. |
| **Мова транскрипції** | `auto`, `uk`, `cs`, `en`; незалежна від мови UI. |
| **Модель / Пристрій / Тип обчислень** | Збережені параметри Whisper. |

У профілі Локальний Whisper **Пристрій** обмежено значеннями `auto`, `cpu` або
`cuda`, а **Тип обчислень** використовує підтримуваний словник CTranslate2.
**Виявити обладнання** виконує обмежену локальну перевірку у фоновому worker;
модель не завантажується, а збережені налаштування не змінюються. Якщо перевірка
недоступна, залиште безпечне `auto/default`. Вибрану пару додатково перевірено
проти встановленого runtime перед завантаженням Whisper.

**Фільтр пауз VAD** увімкнено за замовчуванням і працює лише в профілі Локальний
Whisper. Вимкніть його, якщо фільтр обрізає тиху мову; еквіваленти в CLI —
`--vad` і `--no-vad`. Профілі Ollama й OpenAI ігнорують це налаштування.
| **Модель OpenAI STT** | Використовується лише профілем OpenAI. |
| **Словник JSON** | Детерміновані заміни після розпізнавання. |
| **Локальна модель Ollama** | Установлена модель із capability `audio`. |
| **Оновити** | Повторно перевіряє локальні Ollama-моделі у фоні. |
| **OpenAI key** | Зберігається в OS keychain, не у settings.json. |

## Формати й межі

Підтримуються WAV, MP3, M4A, FLAC, OGG, OPUS, AAC, MP4, MOV, MKV і WEBM.
Локальна перевірка обмежує файл 2 GiB і двома годинами. OpenAI STT приймає
лише свої підтримувані формати й не більше 25 MB. Ollama STT має окрему межу
30 хвилин на одну транскрипцію й зупиняє конвертацію до перевищення memory bound.

| Формат | Вміст |
|---|---|
| TXT | Виправлений текст. |
| MD | Основні metadata та текст. |
| JSON | Повний структурований transcript payload. |
| SRT / VTT | Сегменти з часовими межами; Ollama має один сегмент. |

## Відновлення каталогу моделей

Під час запуску GUI один раз примиряє локальний каталог Faster Whisper, а
команди керування моделями роблять це перед виконанням. Це стосується
`models list`, `models install`, `models verify`, `models remove` та явної
команди відновлення. Примирення працює локально й офлайн: воно самостійно не
завантажує, не оновлює і не видаляє модель.

Перевірку або відновлення можна запустити явно:

```text
voice-studio models reconcile
```

Команда друкує один JSON-об’єкт із полями `status` (`PASS` або `FAIL`), `action`
(`none`, `repaired` або `attention`), `adopted`, `dropped`, `blocked` (кожен
заблокований елемент має `id`, `path`, `reason`), `staging_removed`,
`staging_kept`, `residue_removed` і `catalog_quarantined` (шлях або `null`). Для
помилки також додається `error`. Звичайні команди `models` повідомляють нетривіальний
результат у stderr із префіксом `model-catalog:`; здоровий незмінений каталог
не створює повідомлення.

## Аудит сховища та явна репарація

Запустіть аудит сховища лише для читання:

```text
voice-studio storage audit
```

Саме команда аудиту ніколи не примиряє каталог моделей і не змінює активне
дерево даних. Вона читає SQLite зі стабільного тимчасового знімка бази та WAL
поза деревом даних, потім видаляє цей знімок, а керовані джерела, моделі й
експорти сканує без запису. Верхній `status` і далі описує стан SQLite та
керованих джерел. `missing_records` визначає записи транскриптів зі зниклим
керованим джерелом. Вкладений об'єкт `model_catalog` повідомляє про маніфест,
відсутні, осиротілі й заблоковані моделі, staging і залишки. Вкладений об'єкт
`exports` містить списки звичайних `files`, консервативних кандидатів
`canonical_stale`, файлів `unmanaged` та `blocked` елементів, які є
небезпечними або не є звичайними файлами. Кандидати експорту — лише звіт;
автоматично вони ніколи не видаляються.

Автоматичне примирення й далі відбувається під час запуску GUI та перед кожною
командою `models`. `voice-studio models reconcile` — пряма явна команда. Якщо
запис транскрипту вказує на кероване джерело, відсутність якого доведено,
від'єднайте лише це застаріле посилання:

```text
voice-studio storage repair-missing TRANSCRIPT_ID --expected-path PATH --yes
```

`--expected-path` захищає від репарації запису, що змінився після аудиту;
використовуйте точний шлях із `missing_records`. Репарація очищає лише збережене
посилання на джерело та ознаку retention. Вона ніколи не видаляє і не створює
аудіо заново, не змінює текст транскрипту й не торкається оригінального
медіафайла користувача.

## Резервна копія та локальний стан

Відновлення замінює з архіву транскрипти, налаштування та збережені джерела.
Поточні локальні дерева цієї машини `models/` і `exports/` зберігаються без
змін; вони навмисно залишаються **поза архівом** і ніколи не додаються до
`.voice-backup`.

Перед зміною активного кореня програма перевіряє ці дерева без переходу за
посиланнями. Симлінк, junction або інша Windows reparse point (а також інший
небезпечний спеціальний елемент) перериває відновлення **до** зміни активного
кореня. Користувач побачить конкретну помилку на кшталт `local restore state
contains an unsafe path: <path>`; поточні дані залишаються на місці.

## Приватність

- Ollama працює на фіксованій адресі `127.0.0.1:11434`.
- Cloud не є fallback і не запускається без явного вибору та згоди.
- `raw_text` і raw segment text незмінні.
- API keys не потрапляють у settings, metadata, backup або diagnostics.
- Початковий медіафайл користувача ніколи не видаляється.
