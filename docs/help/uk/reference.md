# Довідка екранів і параметрів

## Ліве меню

| Елемент | Призначення |
|---|---|
| **Огляд** | Локальна статистика всієї історії та останні записи. |
| **Студія** | Запис, транскрибування та редактор. |
| **Словник** | Керований термінологічний словник із імпортом/експортом. |
| **Історія** | Пошук і комбіновані фільтри записів; відкриває запис у Студії. |
| **Моделі** | Керування тільки моделями Faster Whisper. |
| **Резервна копія** | Створення, перевірка й відновлення backup. |
| **Налаштування** | Центральна сторінка: профілі, мова, движки, Ollama й OpenAI. |
| **Довідка** | Центральна сторінка з manual; також F1. |

Налаштування й Довідка відкриваються всередині головного вікна, як Огляд або
Студія. Якщо покинути сторінку Налаштування з незбереженими змінами, програма
запитає: зберегти, відкинути чи залишитися. Моделі та Резервна копія лишаються
окремими вікнами.

Картка **Динаміка** на Огляді додає два графіки під підсумковими картками:
стовпчиковий графік активності за 14 днів (сьогодні — крайній справа стовпчик,
над кожним ненульовим днем — підпис-число) і графік розподілу мов та движків
за найпопулярнішими значеннями, решта об'єднана в "інше". Обидва графіки
малюються прямо на сторінці й перемальовуються при зміні розміру вікна; якщо
за період немає жодного запису, замість порожніх стовпчиків показується текст
про відсутність активності. Рядок стану на кожній сторінці показує тонкий
індикатор прогресу під час виконання завдання — за замовчуванням
невизначений, під час завантаження моделі перемикається на відсотки — а поки
активна черга транскрибування, поруч показується компактний лічильник
"готово/усього".

## Налаштування → Профілі

| Профіль | Розпізнавання | AI-виправлення | Мережа |
|---|---|---|---|
| **Локальна Ollama** | Ollama audio model | Ollama, автоматично | Лише loopback |
| **Локальний Whisper** | Faster Whisper | Вимкнено | Локально |
| **OpenAI cloud** | `gpt-transcribe` або збережений ID | OpenAI вручну | Явна згода |

Налаштування движка розміщені прямо під картками профілів і перемикаються разом
із вибраним профілем: модель Ollama й локальне AI-редагування, параметри Faster
Whisper або моделі та ключ OpenAI. Окремої вкладки «Локальний AI» більше немає.
Якщо жодна встановлена модель Ollama не заявляє capability `audio`, список
показує всі встановлені моделі разом із попередженням, і вибір лишається за вами.

## Налаштування → Синхронізація

Локальне дзеркало для транскриптів — приватна альтернатива хмарній синхронізації:
програма сама нічого не надсилає в мережу, а лише пише файли у вибрану папку, яку
користувач може вказати на будь-яку папку, яку самостійно синхронізує обраний ним
сторонній клієнт (Google Drive, OneDrive тощо).

| Поле | Значення / поведінка |
|---|---|
| **Дзеркалити транскрипти в папку** | Вмикає авто-дзеркалення; вимагає вказаної папки. |
| **Папка синхронізації** + **Вибрати…** | Обирається через системний діалог вибору папки. |
| **Копіювати також аудіо** | Додає до дзеркала збережену керовану копію аудіо, якщо вона є. |
| **Синхронізувати все зараз** | Дзеркалить усі збережені транскрипти у фоновому worker і показує підсумок у рядку стану. |

Кожен транскрипт записується як пара `Markdown` + `JSON` (детерміновані імена
файлів за датою і id); програма нічого не видаляє з цієї папки і не зберігає в
ній жодних ключів доступу. Некоректну папку (неіснує, файл замість каталогу,
symlink, або папка всередині/навколо приватного каталогу даних) буде відхилено
при збереженні з поясненням помилки. Дзеркалення також запускається автоматично
після завершення розпізнавання, збереження правок у редакторі, призначення
спікера та застосування AI-очищення; будь-яка помилка дзеркалення лише
з’являється в рядку стану й ніколи не скасовує сам запис.

## Розпізнавання

| Поле | Призначення |
|---|---|
| **Движок** | Поточний движок, який визначено профілем. |
| **Мова транскрипції** | `auto`, `uk`, `cs`, `en`; незалежна від мови UI. |
| **Модель / Пристрій / Тип обчислень** | Збережені параметри Whisper. |

У профілі Локальний Whisper **Пристрій** обмежено значеннями `auto`, `cpu` або
`cuda`, а **Тип обчислень** використовує підтримуваний словник CTranslate2.
**Виявити обладнання** виконує обмежену локальну перевірку у фоновому worker;
модель не завантажується, а збережені налаштування не змінюються. Якщо перевірка
недоступна, залиште безпечне `auto/default`. Вибрану пару додатково перевірено
проти встановленого runtime перед завантаженням Whisper.

**Фільтр пауз VAD** увімкнено за замовчуванням і працює лише в профілі Локальний
Whisper. Вимкніть його, якщо фільтр обрізає тиху мову; еквіваленти в CLI —
`--vad` і `--no-vad`. Профілі Ollama й OpenAI ігнорують це налаштування.
| **Модель OpenAI STT** | Використовується лише профілем OpenAI. |
| **Словник JSON** | Детерміновані заміни після розпізнавання. |
| **Локальна модель Ollama** | Установлена модель із capability `audio`; якщо таких немає — усі встановлені моделі з попередженням. |
| **Оновити** | Повторно перевіряє локальні Ollama-моделі у фоні. |
| **OpenAI key** | Зберігається в OS keychain, не у settings.json. |

## Інструменти редактора Студії

| Кнопка | Дія |
|---|---|
| **B**, **I** | Жирний і курсив для виділеного тексту. |
| **Пошук і заміна** | Відкриває панель під редактором: пошук з урахуванням регістру та цілого слова, лічильник збігів, «Замінити» і «Замінити все». |
| **Додати до словника** | Створює правило з виділеного тексту й зберігає керований словник. |
| **Слова-паразити** | Показує кожен знайдений збіг із контекстом; прибираються лише позначені. |
| **Оцінка впевненості** | Перелічує сегменти з найнижчою оцінкою впевненості для перегляду. |

Ці інструменти змінюють лише текст у редакторі. Зміни потрапляють у
сховище тільки після «Зберегти правки»; `raw_text` залишається незмінним.
«Додати до словника» недоступне, коли відкрито зовнішній словник лише для
читання або коли на сторінці «Словник» є незбережені зміни. Слова-паразити
беруться зі списку для мови запису, а якщо вона `auto` — з мови розпізнавання
в налаштуваннях.

### Перегляд за оцінкою впевненості

«Оцінка впевненості» відкриває панель зі списком сегментів, оцінка яких нижча
за поріг; спочатку — найнижчі. Оцінка — це власний сигнал впевненості
рушія розпізнавання для цього сегмента: це не ймовірність помилки й не гарантія
точності, тож список задає порядок перегляду, а не вирок. Сегменти, для яких
рушій не дав оцінки, показані після оцінених і позначені як «без оцінки».

Поріг починається з 0.60 і задається в межах від 0.00 до 1.00. Він належить
лише відкритій сторінці: його ніколи не записують у налаштування чи на диск,
тож наступний сеанс знову починається з 0.60. Вибір рядка підсвічує відповідний
сегмент у редакторі й переносить туди курсор; якщо текст сегмента вже змінено
до невпізнанності, панель повідомляє про це замість переходу. «Відтворити
сегмент» запускає локальне відтворення збереженого аудіо від початку цього
сегмента.

### Локальне відтворення

Панель відтворення під редактором програє збережену керовану копію аудіо:
відтворення/пауза, стоп, перемотування на ±5 секунд і швидкість 0.75–2×.
Швидкість реалізована перевибіркою, тож вищий темп підвищує і тон голосу.
Повзунок позиції відстежує відтворення і дозволяє перетягуванням перейти в
будь-яку точку аудіо; поки він утримується, позиція не рухається, і
перемотування відбувається лише при відпусканні, а без доступного для
відтворення аудіо повзунок неактивний. Відтворюється лише керована копія в
сховищі програми; зовнішній оригінальний файл ніколи не розшукується і не
відкривається. Якщо аудіо для запису не збережено, панель повідомляє про це.
Перемикання сторінки чи запису, а також відновлення з резервної копії
зупиняють відтворення.

## Черга транскрипцій

| Елемент керування | Призначення |
|---|---|
| **Черга** | Показує або приховує панель **Черга транскрипцій** над редактором. |
| **Додати файли…** | Відкриває вибір файлів; додаються лише підтримувані медіаформати. |
| **Додати папку…**, **З підпапками** | Додає всі підтримувані файли з папки, рекурсивно, якщо позначено. |
| **Старт** | Запускає обробку файлів, що очікують, по черзі з поточним профілем. |
| **Пауза** / **Продовжити** | Зупиняє чергу після поточного файлу або продовжує її. |
| **Пропустити** | Пропускає вибрані файли, які ще очікують. |
| **Прибрати завершені** | Очищає рядки зі станом «готово», «помилка», «пропущено» чи «скасовано». |
| **Очистити** | Спорожнює чергу; відхиляється, поки файл обробляється. |

Стовпці таблиці — **Файл**, **Стан**, **Секунди** й **Помилка**. У черзі
може бути щонайбільше 500 файлів. Файл зі станом «помилка» чи «скасовано»
записує причину в **Помилка**, і черга продовжує з наступним файлом. У
редакторі відкривається лише останній успішний результат, і ніколи поверх
незбережених правок; закриття програми ставить чергу на паузу.

## Вкладка «Розумний текст»

| Елемент керування | Призначення |
|---|---|
| **Пауза, с** | Проміжок між сегментами, після якого починається новий абзац (0–600 с, за замовчуванням 2.0). |
| **Абзац, с** | Максимальна довжина абзацу, після якої він розбивається (5–3600 с, за замовчуванням 90). |
| **Мітки часу**, **Спікери** | Додають часові мітки або мітки спікерів до тексту. |
| **Оновити** | Перебудовує попередній перегляд із поточного транскрипту й параметрів. |
| **Копіювати** | Копіює текст у буфер обміну. |
| **Експорт MD…**, **Експорт TXT…** | Зберігає текст як Markdown або plain text; типова назва файлу — ім’я джерела без розширення. |
| **Сегменти**, **Призначити спікера…** | Список кожного сегмента (номер · час · фрагмент); виберіть його й уведіть ім’я, щоб підписати, або залиште поле порожнім, щоб прибрати мітку. |

Некоректне значення **Пауза, с** або **Абзац, с** показує повідомлення
«Пауза має бути від 0 до 600 с, а абзац — від 5 до 3600 с.» в рядку стану й
очищає попередній перегляд. Мітки спікерів зберігаються лише в metadata
транскрипту; `raw_text` і текст сегментів ніколи не змінюються. Якщо запис
не вибрано, вкладка показує «Виберіть запис, щоб побачити розумний текст.»

## Формати й межі

Підтримуються WAV, MP3, M4A, FLAC, OGG, OPUS, AAC, MP4, MOV, MKV і WEBM.
Локальна перевірка обмежує файл 2 GiB і двома годинами. OpenAI STT приймає
лише свої підтримувані формати й не більше 25 MB. Ollama STT має окрему межу
30 хвилин на одну транскрипцію й зупиняє конвертацію до перевищення memory bound.

| Формат | Вміст |
|---|---|
| TXT | Виправлений текст. |
| MD | Основні metadata та текст. |
| JSON | Повний структурований transcript payload. |
| SRT / VTT | Сегменти з часовими межами; Ollama має один сегмент. |

## Відновлення каталогу моделей

Під час запуску GUI один раз примиряє локальний каталог Faster Whisper, а
команди керування моделями роблять це перед виконанням. Це стосується
`models list`, `models install`, `models verify`, `models remove` та явної
команди відновлення. Примирення працює локально й офлайн: воно самостійно не
завантажує, не оновлює і не видаляє модель.

Перевірку або відновлення можна запустити явно:

```text
voice-studio models reconcile
```

Команда друкує один JSON-об’єкт із полями `status` (`PASS` або `FAIL`), `action`
(`none`, `repaired` або `attention`), `adopted`, `dropped`, `blocked` (кожен
заблокований елемент має `id`, `path`, `reason`), `staging_removed`,
`staging_kept`, `residue_removed` і `catalog_quarantined` (шлях або `null`). Для
помилки також додається `error`. Звичайні команди `models` повідомляють нетривіальний
результат у stderr із префіксом `model-catalog:`; здоровий незмінений каталог
не створює повідомлення.

## Аудит сховища та явна репарація

Запустіть аудит сховища лише для читання:

```text
voice-studio storage audit
```

Саме команда аудиту ніколи не примиряє каталог моделей і не змінює активне
дерево даних. Вона читає SQLite зі стабільного тимчасового знімка бази та WAL
поза деревом даних, потім видаляє цей знімок, а керовані джерела, моделі й
експорти сканує без запису. Верхній `status` і далі описує стан SQLite та
керованих джерел. `missing_records` визначає записи транскриптів зі зниклим
керованим джерелом. Вкладений об'єкт `model_catalog` повідомляє про маніфест,
відсутні, осиротілі й заблоковані моделі, staging і залишки. Вкладений об'єкт
`exports` містить списки звичайних `files`, консервативних кандидатів
`canonical_stale`, файлів `unmanaged` та `blocked` елементів, які є
небезпечними або не є звичайними файлами. Кандидати експорту — лише звіт;
автоматично вони ніколи не видаляються.

Автоматичне примирення й далі відбувається під час запуску GUI та перед кожною
командою `models`. `voice-studio models reconcile` — пряма явна команда. Якщо
запис транскрипту вказує на кероване джерело, відсутність якого доведено,
від'єднайте лише це застаріле посилання:

```text
voice-studio storage repair-missing TRANSCRIPT_ID --expected-path PATH --yes
```

`--expected-path` захищає від репарації запису, що змінився після аудиту;
використовуйте точний шлях із `missing_records`. Репарація очищає лише збережене
посилання на джерело та ознаку retention. Вона ніколи не видаляє і не створює
аудіо заново, не змінює текст транскрипту й не торкається оригінального
медіафайла користувача.

## Резервна копія та локальний стан

Відновлення замінює з архіву транскрипти, налаштування та збережені джерела.
Поточні локальні дерева цієї машини `models/` і `exports/` зберігаються без
змін; вони навмисно залишаються **поза архівом** і ніколи не додаються до
`.voice-backup`.

Перед зміною активного кореня програма перевіряє ці дерева без переходу за
посиланнями. Симлінк, junction або інша Windows reparse point (а також інший
небезпечний спеціальний елемент) перериває відновлення **до** зміни активного
кореня. Користувач побачить конкретну помилку на кшталт `local restore state
contains an unsafe path: <path>`; поточні дані залишаються на місці.

## Приватність

- Ollama працює на фіксованій адресі `127.0.0.1:11434`.
- Cloud не є fallback і не запускається без явного вибору та згоди.
- `raw_text` і raw segment text незмінні.
- API keys не потрапляють у settings, metadata, backup або diagnostics.
- Початковий медіафайл користувача ніколи не видаляється.
