# Довідка екранів і параметрів

## Ліве меню

| Елемент | Призначення |
|---|---|
| **Студія** | Запис, транскрибування, редактор та історія. |
| **Моделі** | Керування тільки моделями Faster Whisper. |
| **Резервна копія** | Створення, перевірка й відновлення backup. |
| **Налаштування** | Профілі, мова, движки, Ollama й OpenAI. |
| **Довідка** | Відкриває manual; також F1. |

## Налаштування → Профілі

| Профіль | Розпізнавання | AI-виправлення | Мережа |
|---|---|---|---|
| **Локальна Ollama** | Ollama audio model | Ollama, автоматично | Лише loopback |
| **Локальний Whisper** | Faster Whisper | Вимкнено | Локально |
| **OpenAI cloud** | `gpt-transcribe` або збережений ID | OpenAI вручну | Явна згода |

## Налаштування → Загальні

| Поле | Значення / поведінка |
|---|---|
| **Мова інтерфейсу** | `Українська`, `Čeština`, `English`; змінює також Help. |
| **Зберігання аудіо** | `keep` або `delete_after_transcription`; оригінал не видаляється. |
| **Гаряча клавіша** | Default `<f13>`; **Запам’ятати клавішу…** записує нову. |
| **Автоматично копіювати** | Вимкнено за замовчуванням. |
| **Offline-only** | Визначається профілем; локальні профілі не дозволяють cloud. |

## Розпізнавання і Local AI

| Поле | Призначення |
|---|---|
| **Движок** | Поточний движок, який визначено профілем. |
| **Мова транскрипції** | `auto`, `uk`, `cs`, `en`; незалежна від мови UI. |
| **Модель / Пристрій / Тип обчислень** | Збережені параметри Whisper. |
| **Модель OpenAI STT** | Використовується лише профілем OpenAI. |
| **Словник JSON** | Детерміновані заміни після розпізнавання. |
| **Локальна модель Ollama** | Установлена модель із capability `audio`. |
| **Оновити** | Повторно перевіряє локальні Ollama-моделі у фоні. |
| **OpenAI key** | Зберігається в OS keychain, не у settings.json. |

## Формати й межі

Підтримуються WAV, MP3, M4A, FLAC, OGG, OPUS, AAC, MP4, MOV, MKV і WEBM.
Локальна перевірка обмежує файл 2 GiB і двома годинами. OpenAI STT приймає
лише свої підтримувані формати й не більше 25 MB. Ollama STT має окрему межу
30 хвилин на одну транскрипцію й зупиняє конвертацію до перевищення memory bound.

| Формат | Вміст |
|---|---|
| TXT | Виправлений текст. |
| MD | Основні metadata та текст. |
| JSON | Повний структурований transcript payload. |
| SRT / VTT | Сегменти з часовими межами; Ollama має один сегмент. |

## Приватність

- Ollama працює на фіксованій адресі `127.0.0.1:11434`.
- Cloud не є fallback і не запускається без явного вибору та згоди.
- `raw_text` і raw segment text незмінні.
- API keys не потрапляють у settings, metadata, backup або diagnostics.
- Початковий медіафайл користувача ніколи не видаляється.
