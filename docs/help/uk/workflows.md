# Основні сценарії

## Транскрибування через локальну Ollama

1. Запустіть Ollama.
2. У **Налаштування → Профілі** виберіть **Локальна Ollama**.
3. На вкладці **Локальний AI** виберіть аудіосумісну модель й натисніть
   **Зберегти**.
4. У **Студія** натисніть **Транскрибувати файл…** і виберіть файл.

Ollama повертає plain text без надійних часових міток. VOICE Studio створює
один сегмент від початку до фактичної тривалості запису й не вигадує таймкоди.

## Перемикання профілю

Відкрийте **Налаштування → Профілі**, виберіть картку й натисніть
**Зберегти**.

- **Локальна Ollama** — стандартний режим: Ollama розпізнає аудіо й автоматично
  виправляє текст локально.
- **Локальний Whisper** — Faster Whisper розпізнає локально з часовими
  сегментами; автоматичне AI-виправлення вимкнене.
- **OpenAI cloud** — хмарне STT; перед кожним upload програма показує ім’я й
  розмір файлу та просить явну згоду.

Профіль заповнює пов’язані privacy та engine-параметри. Вибрані моделі й
детальні значення зберігаються між перезапусками. Автоматичного переходу до
іншого профілю немає.

## Запис із мікрофона

### Запис з утримуванням

1. Натисніть і утримуйте **● Утримуйте для запису**.
2. Говоріть.
3. Відпустіть кнопку для обробки.

### Постійний запис

1. Натисніть **● Постійний запис**.
2. Говоріть без утримування.
3. Натисніть **■ Зупинити запис**.

Максимальна тривалість одного запису — дві години. Якщо програма повідомляє
про пошкоджений запис, безпечний вибір — не продовжувати та записати ще раз.

## Редагування й експорт

1. Відкрийте результат або запис в **Історії**.
2. Змінюйте тільки вкладку **Виправлений текст**.
3. Натисніть **Зберегти правки**.
4. Виберіть **TXT**, **MD**, **JSON**, **SRT** або **VTT**.

**Оригінал** лише для читання. Для Ollama-профілю SRT/VTT містять один сегмент
на всю тривалість. Для точних сегментів використовуйте **Локальний Whisper**.
Після збереження ручної правки TXT/MD і SRT/VTT містять однаковий виправлений
текст. Правка через межі часових сегментів зливає їх у вже наявний зовнішній
інтервал; програма не створює, не розділяє й не пересуває timecode.

## Ручне AI-редагування

1. Збережіть ручні правки.
2. Натисніть **AI-редагування…**.
3. Перегляньте Before/After і підтвердьте застосування.
4. За потреби використайте **Скасувати AI-редагування**.

Ollama отримує тільки поточний виправлений текст і сегменти. `raw_text` не
змінюється. Для OpenAI потрібна окрема згода на передавання тексту.

## Історія

- Введіть частину імені джерела й натисніть **Пошук** або Enter.
- **Перейменувати** змінює назву запису, але не аудіофайл.
- **Видалити** окремо запитує про керовану копію аудіо.

Початковий файл користувача ніколи не видаляється.

## Резервна копія

У **Резервна копія** можна створити, перевірити або відновити `.voice-backup`.
Архів містить історію, налаштування, словник і, лише за явним вибором, керовані
копії аудіо. Моделі Ollama/Whisper і зовнішні оригінали не включаються.

Якщо відновлення перервано через втрату живлення або примусове завершення
процесу, VOICE Studio завершує або скасовує його під час наступного запуску й
повідомляє результат у рядку стану. Recovery directory залишається на диску в
обох випадках.
