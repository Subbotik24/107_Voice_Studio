# Вирішення проблем

## Ollama недоступна

### Симптом

Повідомлення вказує, що Ollama недоступна на `127.0.0.1:11434`, або список
моделей порожній.

### Що зробити

1. Запустіть установлену Ollama.
2. Перевірте `ollama list` у PowerShell.
3. Відкрийте **Налаштування → Локальний AI** й натисніть **Оновити**.
4. Виберіть модель і натисніть **Зберегти**.

## Модель Ollama не підтримує аудіо

### Симптом

Програма повідомляє, що вибрана модель не має capability `audio`.

### Що зробити

Установіть або виберіть в Ollama аудіосумісну модель. VOICE Studio не
встановлює й не оновлює Ollama-моделі автоматично та не перемикається на
Whisper без вашого вибору.

## Ollama не повернула транскрипт

### Симптом

Програма повідомляє `Ollama returned no transcript` і не створює порожній
запис.

### Що зробити

1. У **Налаштування → Розпізнавання** виберіть мову, яка відповідає запису,
   або `auto`.
2. Повторіть обробку короткого чіткого фрагмента.
3. Якщо модель не підтримує фактичну мову аудіо, виберіть профіль
   **Локальний Whisper**. VOICE Studio не підміняє движок автоматично.

## Запис для Ollama довший за 30 хвилин

Профіль Ollama зупиняє локальну конвертацію на межі 30 хвилин, не накопичуючи
WAV без обмеження. Виберіть **Локальний Whisper** для довшого запису або
розділіть робочу копію файлу; оригінал не перезаписуйте.

## AI-виправлення не виконано

### Симптом

Транскрипт відкрився, але metadata або повідомлення містить cleanup warning.

### Причина

Перший Ollama-запит успішно розпізнав аудіо, а другий повернув помилку або
невалідний structured output.

### Що зробити

Збережений raw transcript не втрачено. Перевірте Ollama й запустіть
**AI-редагування…** вручну або виправте текст у редакторі.

## Модель Whisper не встановлена

Ця помилка стосується лише профілю **Локальний Whisper**. Відкрийте **Моделі**,
імпортуйте або завантажте сумісну модель, натисніть **Перевірити**, а потім
збережіть її точний ID у налаштуваннях.

## Медіафайл не відкривається

Перевірте розширення, наявність аудіодоріжки, локальне відтворення та межі
2 GiB / дві години. Для незвичного codec створіть копію у WAV або MP3, не
перезаписуючи оригінал.

## Налаштування не збереглися

Натискайте **Зберегти**, а не **Скасувати**. Якщо програма повідомляє про
пошкоджений settings JSON, перевірте всі вкладки й збережіть валідні значення.
Після збереження перезапуск має відтворити той самий профіль і моделі.

## Гаряча клавіша недоступна

Кнопка запису продовжує працювати. У **Налаштування → Загальні** захопіть іншу
комбінацію й перевірте системні дозволи вводу.

## Windows SmartScreen

Поточний Test RC не має цифрового підпису. Перевірте джерело ZIP і SHA-256.
Не запускайте файл, якщо джерело або hash не збігаються.

## Якщо проблема не зникла

Створіть redacted report:

```text
voice-studio diagnostics --export report.json
```

Не додавайте приватне аудіо, transcript text, API keys, backup, database або
повні локальні шляхи.
