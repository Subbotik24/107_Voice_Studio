# Вирішення проблем

## Модель faster-whisper не встановлена

### Симптом

Обробка повідомляє, що модель не встановлена, і пропонує команду
`voice-studio models install MODEL`.

### Причина

Значення **Налаштування → Розпізнавання → Модель** не знайдено в локальному
керованому каталозі й не є доступною директорією моделі.

### Що зробити

1. Відкрийте **Моделі**.
2. Імпортуйте наявну локальну модель або завантажте модель із налаштованого
   release registry.
3. Виберіть її та натисніть **Перевірити**.
4. Скопіюйте точний ID у поле **Модель** і збережіть налаштування.

## Режим offline-only забороняє завантаження

### Симптом

Вікно моделей показує **Режим offline-only забороняє завантаження.**

### Причина

У **Налаштування → Загальні** ввімкнено заборону мережевих операцій.

### Що зробити

Імпортуйте вже наявну локальну модель. Вимикайте `offline-only` лише якщо
свідомо дозволяєте download із налаштованого HTTPS registry.

## Медіафайл не відкривається

### Симптом

Програма повідомляє про непідтримуване розширення, відсутню аудіодоріжку,
порожній файл, перевищення розміру/тривалості або неможливість декодування.

### Причина

Файл не проходить локальну validation або codec усередині контейнера не
підтримується встановленим runtime.

### Що зробити

1. Переконайтеся, що файл має підтримуване розширення.
2. Перевірте, що в ньому є аудіо та він відтворюється локально.
3. Для незвичного codec створіть копію у WAV або MP3. Не перезаписуйте
   початковий файл.
4. Перевірте межі: не більше 2 GiB і двох годин.

## Транскрибування зупинено або перевищило timeout

### Симптом

Рядок стану показує скасування або повідомлення з назвою фази й timeout.

### Причина

Користувач натиснув **Скасувати**, операція перевищила налаштований budget або
worker завершився з помилкою.

### Що зробити

1. Дочекайтеся повернення стану **Готово**.
2. Перевірте, що модель існує й проходить **Моделі → Перевірити**.
3. Повторіть дію на короткому тестовому файлі.
4. Якщо проблема повторюється, створіть redacted report командою
   `voice-studio diagnostics --export report.json`.

Не додавайте до report приватний медіафайл або transcript text.

## Гаряча клавіша недоступна

### Симптом

З’являється **Гаряча клавіша недоступна: … Кнопка запису працює.**

### Причина

Комбінація зайнята, listener не має потрібного системного дозволу або ОС не
може зареєструвати її.

### Що зробити

1. Використовуйте кнопку запису — основний сценарій залишається доступним.
2. У **Налаштування → Загальні** виберіть **Запам’ятати клавішу…** і натисніть
   іншу комбінацію.
3. Перевірте системні дозволи Accessibility/Input для програми, якщо ваша ОС
   їх вимагає.

## Пошкоджений запис

### Симптом

Після зупинки мікрофона з’являється діалог **Пошкоджений запис** із питанням,
чи продовжити.

### Причина

Recorder зафіксував втрату аудіоблоків або іншу деградацію capture.

### Що зробити

1. Залиште безпечний default **Ні**.
2. Перевірте вибраний Windows input device і навантаження системи.
3. Повторіть короткий запис.

Продовжуйте лише якщо неповний запис прийнятний і ви розумієте ризик пропусків.

## Ollama недоступна

### Симптом

Програма повідомляє, що Local Ollama недоступна на `127.0.0.1:11434`, або поле
моделей порожнє.

### Причина

Ollama не запущена, працює не на стандартному loopback endpoint або не має
встановлених моделей.

### Що зробити

1. Запустіть уже встановлену Ollama.
2. Переконайтеся, що потрібна модель доступна в Ollama.
3. Відкрийте **Налаштування → Локальний AI** і натисніть **Оновити**.
4. Виберіть іншу встановлену модель, якщо runtime повідомляє про відсутній
   компонент поточної.

VOICE Studio не встановлює Ollama-моделі автоматично.

## AI-пропозиція застаріла

### Симптом

З’являється **AI-редагування застаріло — правки не застосовано**.

### Причина

Транскрипт змінився після створення Before/After proposal.

### Що зробити

Збережіть актуальні ручні правки й запустіть **AI-редагування…** повторно.
Стару пропозицію не намагайтеся застосовувати.

## Неможливо зберегти, скопіювати або експортувати

### Симптом

Програма просить спочатку створити або вибрати транскрипт.

### Причина

У редакторі немає активного запису з історії.

### Що зробити

Виконайте нове транскрибування або виберіть запис у **Історії**, потім повторіть
дію.

## Файл налаштувань пошкоджений

### Симптом

На старті показано повідомлення, що файл налаштувань пошкоджений і використано
безпечні значення за замовчуванням.

### Причина

Settings JSON не читається або містить типи/значення, які не проходять strict
validation.

### Що зробити

1. Відкрийте **Налаштування**.
2. Перевірте всі три вкладки.
3. Задайте потрібні значення та натисніть **Зберегти**.
4. Якщо помилка повторюється, створіть redacted diagnostics report.

## Backup не перевіряється або не відновлюється

### Симптом

VOICE Studio повідомляє про manifest, version, member, size або SHA-256 error.

### Причина

Архів неповний, змінений, має непідтримувану версію або порушує ZIP safety
limits.

### Що зробити

1. Не відновлюйте такий файл.
2. Повторіть **Резервна копія → Перевірити…** з іншою копією.
3. За можливості створіть новий backup із початкового сховища.

## Відновлення перервано, і історія виглядає порожньою

### Симптом

Відновлення з backup було перервано (втрата живлення, примусове завершення
процесу), а поряд зі сховищем видно каталоги `*.restore-*` і `*.recovery-*`.

### Причина

Підміна сховища не завершилася. VOICE Studio веде журнал відновлення
(`.<ім'я сховища>.restore-journal.json`) саме для цього випадку.

### Що зробити

1. Запустіть VOICE Studio ще раз. Під час запуску відновлення буде або
   завершено, або скасовано, а результат з'явиться в рядку стану.
2. Якщо програма показує попередження про журнал відновлення, нічого не
   видаляйте вручну і створіть redacted diagnostics report.
3. Каталог `*.recovery-*` містить дані, що були до відновлення. Він ніколи не
   видаляється автоматично; приберіть його самостійно лише після перевірки
   історії.

## Windows SmartScreen показує попередження

### Симптом

Windows попереджає про невідомого видавця.

### Причина

VOICE Studio 0.3.0 Test RC не має цифрового підпису.

### Що зробити

Перевірте, що ZIP отримано з очікуваного GitHub repository, і звірте SHA-256 з
опублікованим checksum. Не запускайте файл, якщо джерело або hash не збігаються.

## Якщо проблема не зникла

Створіть redacted report:

```text
voice-studio diagnostics --export report.json
```

У зверненні вкажіть версію VOICE Studio, Windows edition, короткі кроки й точне
повідомлення. Не прикріплюйте приватне аудіо, транскрипти, API keys, backup,
database або повні локальні шляхи.
